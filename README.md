# Tá chegando, Matheus! ✈️

Countdown page for the trip to Brazil: total hours to the flight, remaining work hours (weekdays, excluding lunch and days off), nights of sleep left, and a small calendar.

All times are computed in `America/Los_Angeles`. Settings are saved in the browser's localStorage.

Live: https://matheuscgh-ops.github.io/countdow-matheus/
